## About

**Tablefly Studio** is a web design studio built for one industry only — food. We design fast, photo-led websites for restaurants, cafés and food brands, with menus, direct ordering and booking enquiries built in.

Based in India, working worldwide. Every project starts the same way: we build a **free working demo of the restaurant's own homepage first** — the client judges real work, not promises — and a finished site goes live in 5–7 working days.
